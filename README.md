# Clean Spaces — Website Starter

A responsive, static website starter for a kitchen design, built-in cabinetry and interiors company. Built with plain HTML, CSS and JavaScript so it is easy to customise with Claude Code or any editor.

## Run locally
Open `index.html` in a browser. For a local development server, use the VS Code Live Server extension or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.

## Before showing/publishing to the client
1. **Replace the temporary wordmark** in `index.html` with the logo supplied by Clean Spaces. If you have a transparent PNG or SVG, put it in `assets/` and update the `.brand` markup.
2. **Replace all inspiration photos** with the client's actual project photos. The current images load from Unsplash and are illustrative placeholders, not work completed by Clean Spaces.
3. **Confirm the real service area, contact details, phone/WhatsApp, email and social profiles.** None have been invented in this starter.
4. In `script.js`, replace `hello@example.com` with the client's confirmed email, or connect the form to Formspree, Netlify Forms, a custom API or another service.
5. Update the service list and copy to reflect exactly what Clean Spaces offers (e.g. kitchen design, manufacturing, installation, renovations, built-in cupboards).
6. Check image licences, alt text, SEO metadata and mobile layout before launch.

## Structure
- `index.html` — semantic page structure and copy
- `styles.css` — design system, layout and responsive styles
- `script.js` — mobile menu, current year and demo email enquiry
- `assets/` — place client logo and other local assets here

## Design direction
Warm off-white, muted stone and olive-grey tones; editorial typography; large architectural imagery; clear service/process sections; prominent enquiry form. The layout is inspired by patterns common to premium kitchen/joinery portfolios, not copied from a specific company.
