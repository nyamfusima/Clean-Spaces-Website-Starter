# public/videos

The exported hero montage lives here, as `hero-montage.mp4` (plus an optional
`hero-montage.webm` and `hero-montage-poster.jpg`).

It is generated by `npm run hero:montage` from the authorised source clips in
`media/hero-source/`. See that folder's README for which clips are needed.

Until a montage exists, `heroVideo` in `src/site.config.ts` stays `null` and the
hero uses its still photograph. Nothing here is required for the site to build
or run.
